# CodeAncestry MVP — working concept

A static, dependency-free prototype for the idea of software genealogy:
digital genomes, inherited capabilities, mutations, and connected agents.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080

## Product hypothesis

Git stores history at the line/commit level.
CodeAncestry adds a semantic lineage layer:

- parent/child project relationships
- inherited vs locally mutated capabilities
- agent knowledge exchange
- mutation proposals and compatibility testing
- upward/downward propagation of improvements
- verifiable ancestry for software, agents, and robots
